# dijkstras-algorithm-php

Учебная реализация алгоритма Дейкстры для PHP 8.1+.

Проект находит кратчайшие пути во взвешенном ориентированном графе и показывает не только итоговую стоимость, но и сам маршрут.

## Возможности

- поиск кратчайшего пути между двумя вершинами;
- расчёт расстояний от начальной вершины до всех остальных;
- восстановление маршрута;
- поддержка целых и дробных весов;
- автоматическое добавление вершин, указанных только как соседи;
- проверка структуры графа и запрет отрицательных весов;
- приоритетная очередь `SplPriorityQueue`;
- совместимость со старым API `dijkstra::find()`;
- тесты на PHP 8.1–8.4.

> Алгоритм Дейкстры работает только с неотрицательными весами. Для графов с отрицательными рёбрами нужен другой алгоритм, например Беллмана — Форда.

## Установка

```bash
composer require da41b94c/dijkstras-algorithm-php
```

До публикации пакета в Packagist репозиторий можно подключить через секцию `repositories` Composer или клонировать напрямую.

## Поиск кратчайшего пути

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Da41b94c\Dijkstra\Dijkstra;

$graph = [
	'A' => [
		'B' => 9,
		'C' => 3,
	],
	'C' => [
		'B' => 4,
		'D' => 7,
	],
	'B' => [
		'D' => 1,
	],
	'D' => [],
];

$result = (new Dijkstra())->findShortestPath($graph, 'A', 'D');

$result['distance']; // 8
$result['path'];     // ['A', 'C', 'B', 'D']
```

Метод возвращает массив:

```php
[
	'distance' => 8,
	'path' => ['A', 'C', 'B', 'D'],
]
```

Если путь отсутствует, `distance` равен `INF`, а `path` — пустой массив.

## Расстояния до всех вершин

```php
$distances = (new Dijkstra())->findAllShortestDistances($graph, 'A');

// [
//     'A' => 0,
//     'B' => 7,
//     'C' => 3,
//     'D' => 8,
// ]
```

Недостижимые вершины получают расстояние `INF`.

## Неориентированный граф

Рёбра задаются явно. Чтобы получить неориентированную связь, добавьте оба направления:

```php
$graph = [
	'A' => ['B' => 5],
	'B' => ['A' => 5],
];
```

## Проверка входных данных

Каждая вершина должна содержать массив соседей, а вес ребра — конечное неотрицательное число `int` или `float`.

При пустом графе, отсутствующей стартовой/целевой вершине, строковом весе, `NAN`, `INF` или отрицательном весе выбрасывается `InvalidArgumentException`.

## Старый API

Исходный вызов сохранён как совместимый адаптер:

```php
$times = [
	'B' => 9,
	'C' => 3,
	'D' => INF,
];

$parents = [
	'B' => 'A',
	'C' => 'A',
	'D' => null,
];

$algorithm = new dijkstra();
$minTime = $algorithm->find($graph, $times, $parents, 'D');

// 8
```

Для нового кода рекомендуется `Da41b94c\Dijkstra\Dijkstra`: ему не нужны заранее подготовленные `$times` и `$parents`, и он возвращает маршрут.

## Сложность

Реализация использует список смежности и `SplPriorityQueue`.

- время: `O((V + E) log V)`;
- память: `O(V + E)`.

Здесь `V` — количество вершин, `E` — количество рёбер.
